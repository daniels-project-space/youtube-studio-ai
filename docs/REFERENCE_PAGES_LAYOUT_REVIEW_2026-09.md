Use the accepted Lo-fi study layout as shared presentation, with distinct content and warm Lore/cool Lo-fi accents. A small shared CSS module replaces two old stylesheets; no generic workflow framework or new client-state layer is introduced. Each page remains its own server component. Lore now uses the existing manifest presentation adapter, preserving the exact approved image and rejecting historical material instead of relying on a hard-coded path. The actual image and Golden return links replace an otherwise actionless reference page.

Always show the image, concise composition cues and the full-story illustration rule. Put detailed continuity, original-plan/critic, runtime qualification, release evidence and archive-only boundaries in one keyboard-operable native disclosure. No spinner, imaginary progress, rotating seal or decorative storyboard is needed for a static reference. This does not qualify or unlock Lore rendering.
