No backend billing estimate is claimed for this structural saving.

Reuse the existing standalone-family visibility rule: grouped channels leave the main strip only when their room can surface them; incomplete groups remain accessible, and explicit selected-family/paused-channel views still work. The carousel is smaller, scrollable, keyboard-operable and manually controlled, without hidden clones or automatic movement under the pointer. Active labels no longer imply a connected live broadcast. All retained artwork is unchanged.
